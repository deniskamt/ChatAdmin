# ChatAdmin — бот аукциона

Телеграм-бот для канала-аукциона. Умеет:

1. **Правила в комментариях** — под каждым новым постом канала оставляет
   inline-кнопку со ссылкой на правила (Telegraph).
2. **Меню аукциона в личке** (`/start`):
   - 🔨 **Сделать ставку** — список активных лотов по 10 на страницу
     (навигация «◀️/▶️»), карточка лота с описанием и списком ставок,
     кнопка «💰 Поставить».
   - 📝 **Запросить пост** — заявка уходит администратору в личку.
   - 📜 **Правила** — ссылка на правила.
3. **Админ-команды** (для `ADMIN_IDS`): `/addlot` — добавить лот,
   `/lots` — список всех лотов, `/dellot <id>` — снять лот с аукциона.

## Раздел 1. Правила в комментариях

## Как это работает

В Telegram комментарии под постами канала — это привязанная к каналу
**группа обсуждения**. Когда в канале выходит пост, Telegram сам пересылает его
в эту группу и открывает ветку комментариев. Бот ловит такую автопересылку и
отвечает на неё сообщением с **inline-кнопкой**, которая ведёт на страницу
правил в **Telegraph**.

## Создание страницы правил (один раз)

```bash
python create_telegraph.py
```

Скрипт опубликует правила в Telegraph и напечатает строку `RULES_URL = https://telegra.ph/...`.
Эту ссылку вставьте в переменную `RULES_URL`. Текст правил можно отредактировать
в файле `create_telegraph.py` и запустить скрипт снова.

## Подготовка в Telegram

1. Создайте бота у [@BotFather](https://t.me/BotFather) и получите токен.
2. Привяжите к каналу группу обсуждения:
   *Управление каналом → Обсуждение → выбрать/создать группу*.
3. Добавьте бота в эту **группу обсуждения** и сделайте его **администратором**
   с правом отправки сообщений.
4. В [@BotFather](https://t.me/BotFather) для бота отключите Privacy Mode
   (`/setprivacy` → `Disable`), чтобы он видел сообщения в группе.

## Установка и запуск

```bash
pip install -r requirements.txt

cp .env.example .env
# отредактируйте .env: BOT_TOKEN, RULES_URL, при желании COMMENT_TEXT и CHANNEL_ID

python bot.py
```

## Настройки (`.env`)

| Переменная     | Назначение                                                                 |
|----------------|----------------------------------------------------------------------------|
| `BOT_TOKEN`        | Токен бота от @BotFather. **Обязательно.**                                  |
| `BOT_USERNAME`     | (Необязательно) username бота без `@` — для справки и проверки при запуске.  |
| `RULES_URL`        | Ссылка на страницу правил в Telegraph (из `create_telegraph.py`). **Обязательно.** |
| `COMMENT_TEXT`     | Текст сообщения над кнопкой.                                                 |
| `BUTTON_TEXT`      | Подпись inline-кнопки со ссылкой на правила.                                 |
| `CHANNEL_USERNAME` | (Необязательно) `@username` канала, под постами которого публиковать правила.|
| `CHANNEL_ID`       | (Необязательно) то же ограничение, но по числовому id (для приватных каналов).|
| `ADMIN_IDS`        | id админов через запятую (заявки на пост + управление лотами).               |
| `ANON_BIDS`        | `1` — показывать ставки анонимно, `0` — с `@username`.                       |
| `DB_PATH`          | Путь к файлу БД аукциона. На Railway укажите путь внутри Volume.             |

## Раздел 2. Аукцион (меню в личке)

1. Узнайте свой Telegram id (напишите [@userinfobot](https://t.me/userinfobot))
   и впишите его в `ADMIN_IDS`.
2. Откройте бота в личке и отправьте `/start` — появится меню.
3. Админ добавляет лоты: `/addlot` (бот спросит название и описание).
   Список — `/lots`, снять лот — `/dellot <id>`.
4. Пользователи выбирают лот, видят описание и ставки, жмут «💰 Поставить»
   и вводят сумму (должна превышать текущую максимальную ставку).

> **Хранение данных.** Аукцион хранится в SQLite (`DB_PATH`). На Railway
> файловая система временная — чтобы лоты и ставки не пропадали при
> передеплое, добавьте **Volume** (например, на `/data`) и задайте
> `DB_PATH=/data/auction.db`.

## Деплой на Railway

Бот работает на long-polling, поэтому открытый порт ему не нужен — это
обычный фоновый процесс (`worker`).

1. Создайте новый проект на [railway.app](https://railway.app) →
   **Deploy from GitHub repo** и выберите этот репозиторий (ветку с ботом).
2. Railway сам определит Python по `requirements.txt` и запустит
   `python bot.py` (команда задана в `railway.json`).
3. Откройте сервис → вкладка **Variables** и добавьте переменные:
   - `BOT_TOKEN` — токен от @BotFather
   - `BOT_USERNAME` — (опц.) username бота без `@`
   - `RULES_URL` — ссылка на страницу правил в Telegraph
   - `COMMENT_TEXT` — (опц.) текст над кнопкой
   - `BUTTON_TEXT` — (опц.) подпись кнопки
   - `CHANNEL_USERNAME` — (опц.) `@username` канала для ограничения
   - `CHANNEL_ID` — (опц.) то же по числовому id (приватные каналы)

   Переменные из дашборда Railway подхватываются автоматически — файл `.env`
   на сервере не нужен.
4. Деплой запустится сам. Логи смотрите во вкладке **Deployments → Logs**;
   при ошибке процесс перезапустится (`restartPolicyType: ALWAYS`).

> Важно: запускайте **только один экземпляр** бота. Если параллельно работает
> локальная копия и копия на Railway, Telegram будет отдавать обновления с
> ошибкой `Conflict: terminated by other getUpdates request`.

## Запуск как сервис (опционально)

Пример systemd-юнита `/etc/systemd/system/chatadmin-bot.service`:

```ini
[Unit]
Description=ChatAdmin rules bot
After=network.target

[Service]
WorkingDirectory=/opt/ChatAdmin
ExecStart=/usr/bin/python3 /opt/ChatAdmin/bot.py
Restart=always

[Install]
WantedBy=multi-user.target
```
