# ChatAdmin — бот «правила в комментариях»

Телеграм-бот, который под **каждым новым постом канала** автоматически
оставляет в комментариях ссылку на правила чата.

## Как это работает

В Telegram комментарии под постами канала — это привязанная к каналу
**группа обсуждения**. Когда в канале выходит пост, Telegram сам пересылает его
в эту группу и открывает ветку комментариев. Бот ловит такую автопересылку и
отвечает на неё — его ответ становится первым комментарием под постом.

## Подготовка в Telegram

1. Создайте бота у [@BotFather](https://t.me/BotFather) и получите токен.
2. Привяжите к каналу группу обсуждения:
   *Управление каналом → Обсуждение → выбрать/создать группу*.
3. Добавьте бота в эту **группу обсуждения** и сделайте его **администратором**
   с правом отправки сообщений.
4. В [@BotFather](https://t.me/BotFather) для бота отключите Privacy Mode
   (`/setprivacy` → `Disable`), чтобы он видел сообщения в группе.

## Установка и запуск

```bash
pip install -r requirements.txt

cp .env.example .env
# отредактируйте .env: BOT_TOKEN, RULES_URL, при желании COMMENT_TEXT и CHANNEL_ID

python bot.py
```

## Настройки (`.env`)

| Переменная     | Назначение                                                                 |
|----------------|----------------------------------------------------------------------------|
| `BOT_TOKEN`    | Токен бота от @BotFather. **Обязательно.**                                  |
| `RULES_URL`    | Ссылка на правила (сообщение в канале или внешний URL).                     |
| `COMMENT_TEXT` | Текст комментария, HTML. `{rules_url}` подставляется автоматически.         |
| `CHANNEL_ID`   | (Необязательно) ограничить бота одним каналом по числовому id.              |

## Запуск как сервис (опционально)

Пример systemd-юнита `/etc/systemd/system/chatadmin-bot.service`:

```ini
[Unit]
Description=ChatAdmin rules bot
After=network.target

[Service]
WorkingDirectory=/opt/ChatAdmin
ExecStart=/usr/bin/python3 /opt/ChatAdmin/bot.py
Restart=always

[Install]
WantedBy=multi-user.target
```
